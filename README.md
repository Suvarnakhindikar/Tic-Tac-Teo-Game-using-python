#  Tic-Tac-Toe Game (Python Tkinter)

## 📖 Overview
This project is a simple **Tic-Tac-Toe** game developed using Python and the Tkinter library. It provides a graphical user interface (GUI) where two players can play the classic Tic-Tac-Toe game by taking turns marking X and O on a 3×3 grid.
The application automatically detects the winner or a draw and allows players to restart the game.
---

## ✨ Features
* Graphical User Interface (GUI) using Tkinter
* Two-player gameplay (Player X and Player O)
* Automatic winner detection
* Draw detection
* Restart button to start a new game
* Simple and user-friendly interface
---

## 🛠 Technologies Used
* Python 3
* Tkinter (Built-in Python GUI Library)

## ▶️ How to Run
1. Make sure Python 3 is installed on your computer.
2. Download or clone this repository.
```bash
git clone https://github.com/Suvarnakhindikar/Tic-Tac-Toe-Python.git
```

3. Navigate to the project folder.
```bash
cd Tic-Tac-Toe-Python
```

4. Run the program.
```bash
python tic_tac_toe.py
```

## 🎯 Game Rules
* The game is played between Player X and Player O.
* Players take turns clicking an empty cell.
* The first player to place three identical symbols in a row, column, or diagonal wins.
* If all cells are filled without a winner, the game ends in a draw.
